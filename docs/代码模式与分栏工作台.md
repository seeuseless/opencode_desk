# 代码模式与分栏工作台

> 以代码为准，改动后同步。

## 触点清单

- `src/renderer/components/Sidebar.tsx`
  - `workspaceList(projectPath, dirPath)` 按目录懒加载；缓存键为「项目路径 + NUL + 相对目录」。
  - 只有普通项目在代码模式下展开代码树；`builtin` 的「任务」目录始终展示会话，不请求文件树。
  - 代码模式空项目引导不显示「选择文件夹」。
- `src/renderer/components/CodeWorkspace.tsx`
  - 使用 CodeMirror 6，按文件扩展名通过 `loadLanguage` 加载语法包。
  - 同一项目内保留多个打开文件，标签横向滚动；每个文件独立保存 `content`、`savedContent`、`mtimeMs`。
  - 挂载时按 `openFiles` 恢复项目文件；关闭标签通过 `onOpenFilesChange` 通知 App 更新该项目记忆。
  - 当前文件路径与「已保存/未保存」状态通过 `onStatusChange` 上报，由 `Titlebar` 显示在主标题栏左侧；刷新、保存也在同一行。
  - 保存、重新读取、Ctrl+S 都只作用于当前文件；保存时把磁盘返回的 `mtimeMs` 写回草稿。
- `electron/preload/index.ts`
  - 渲染层通过 `workspaceList`、`workspaceRead`、`workspaceWrite` 访问项目文件。
- `electron/main/index.ts`
  - IPC 入口：`workspace:list`、`workspace:read`、`workspace:write`。
  - 主进程先做项目根目录 realpath/relative 边界校验，忽略符号链接，只允许代码/文本扩展名和 2 MB 以下文本；写入前用 `mtimeMs` 检测外部修改。
- `src/renderer/App.tsx`
  - 普通模式侧栏宽度持久化到 `qingniao.sidebarWidth.normal`，代码模式侧栏宽度持久化到 `qingniao.sidebarWidth.code`，范围 200–420 px；旧的 `qingniao.sidebarWidth` 仅作为首次迁移兜底。
  - `chatWidth` 持久化到 `qingniao.chatWidth`，只用于代码模式；首次默认取内容区约 36%，聊天区最小 320 px，代码区最小 260 px。
  - `qingniao.normalChatWidth` 持久化非代码模式的聊天内容列宽，默认 960 px、可调 640–1100 px；通过 `--chat-content-width` 作用于 `.col`，不改变代码模式分栏。
  - 两个拖拽条使用 pointer capture + 全屏拖拽护罩；左侧宽度随指针右移变大，代码/聊天分隔条随指针右移让聊天变窄。
  - `CodeWorkspace` 以项目 id 为 key；标签切换通过 `onActiveFile` 同步左侧树选中项。
  - `qingniao.codeFiles` 保存「项目路径 → 打开路径列表 + 当前路径」；项目切换、添加已有项目、删除项目和应用重启都按路径恢复，移除项目时同步清理对应记忆。
- `src/renderer/components/ChatView.tsx`、`Titlebar.tsx`
  - `codeMode` 下隐藏权限、思考、浏览入口和标题栏浏览器按钮，并阻止 Markdown 链接触发内置浏览器。
- `src/renderer/codeStyle.ts`、`SettingsView.tsx`、`src/renderer/index.css`
  - 代码风格由 `data-code-style` 和 `data-code-dark` 驱动，CodeMirror 与聊天 highlight.js 共用 `--code-*` token。
  - 全局滚动条统一为细、低对比样式，CodeMirror 内部滚动也继承该规则。
- `src/renderer/components/ModelPicker.tsx`
  - 模型级联菜单测量面板位置，靠窗口边缘时自动平移；二级模型列宽度不超过视口。
