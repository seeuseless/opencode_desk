# 计划任务立即执行链路

> 以代码为准，改动后同步。

## 关键触点

- `electron/main/scheduler.ts`：计划任务入口。创建会话后调用 `/session/{id}/prompt_async`，内核受理 prompt 后立即返回；`runningTaskIds` 仍防止同一任务重复启动。
- `electron/main/adapter.ts`：对 `message` 和 `prompt_async` 两种 POST 端点统一执行模型校正。
- `electron/main/index.ts` / `electron/preload/index.ts`：通过 `schedule:ran` 把已启动的会话 id 通知渲染层。
- `src/renderer/App.tsx`：收到 `schedule:ran` 后补拉内置「任务」目录会话；立即执行启动后只展开左侧「任务」目录，不切换当前会话窗口。
- `src/renderer/components/SchedulesView.tsx`：立即执行按钮只在“请求内核受理”期间显示转圈，执行期间的模型任务由会话行状态表示。
